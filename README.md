# MyCV-FAR

An Excel Add-in designed to streamline the preparation and validation of import files for the annual Faculty Activity Reporting (FAR) cycle in the MyCV system.

## Features

- **MyCV User Search:** Search for and verify users within the MyCV system.
- **BUID Validation:** Validate BUIDs before generating import files to help ensure accurate user and reviewer records.
- **User Import File Generation:** Create the MyCV Users CSV import file required for the annual FAR cycle.
- **Reviewer Import File Generation:** Create the MyCV Reviewers CSV import file.
- **Grant Submission Date Validation:** Check the grants import file for missing or blank proposal submission dates and identify records that need attention before importing.

## How to Install

1. **Download the MyCVToolkit ZIP File**  
   Click [here](https://github.com/lsementa/MyCV-FAR/releases) and select the latest release of the MyCVToolkit installation package.

2. **Extract the Contents**  
   Locate the downloaded ZIP file, extract its contents, and open the folder.

3. **Run the Installer**  
   Double-click on `Setup.exe` to start the installation process.  
   > **Note**: If Microsoft Defender SmartScreen appears, click **More Info** and then **Run Anyway** to proceed.

4. **Verification**  
   Verify the publisher has been verified and click install.

## How to Uninstall

1. **Open Add or Remove Programs**  
   On your Windows device, search for "Add or Remove Programs" in the Start menu.

2. **Find MyCVToolkit**  
   Scroll through the list or search for **MyCVToolkit**.

3. **Uninstall**  
   Select **MyCVToolkit**, click **Uninstall**, and follow the prompts to remove the application.
